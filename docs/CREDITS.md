# Credits

This firmware is built on open-source work. Nothing here is vendored silently:
the entries below are the libraries and assets the UI and runtime depend on.

## Runtime and drivers

| Component | Used for | License |
| --- | --- | --- |
| [LVGL](https://lvgl.io) 8.4 | whole UI: widgets, canvas layer, fonts | MIT |
| [wasm3](https://github.com/wasm3/wasm3) | Applet runtime (`third_party/wasm3`) | MIT |
| [esp32-camera](https://github.com/espressif/esp32-camera) | OV5640 driver and DVP capture | Apache-2.0 |
| [esp_lcd_touch_xpt2046](https://components.espressif.com/components/atanisoft/esp_lcd_touch_xpt2046) | resistive touch driver | Apache-2.0 |
| [ESP-IDF](https://github.com/espressif/esp-idf) | build system, `esp_lcd`, FreeRTOS | Apache-2.0 |

## Type and iconography

| Asset | Used for | License |
| --- | --- | --- |
| [IBM Plex Sans](https://github.com/IBM/plex) | all UI text, converted to bitmap at 14, 16 and 20 px | SIL OFL 1.1 |
| [Montserrat](https://github.com/JulietaUla/Montserrat) | the symbol font LVGL ships, used for the tab icons | SIL OFL 1.1 |
| [Font Awesome Free 4.7](https://fontawesome.com/v4/) | the tab bar icons (`LV_SYMBOL_*` glyphs bundled in LVGL's Montserrat fonts) | CC BY 4.0 |

The tab bar does not ship a separate icon file: it renders the `LV_SYMBOL_*`
glyphs that LVGL already embeds, which come from Font Awesome Free. Credit for
those glyphs belongs to Font Awesome.

`main/src/fonts/plex_*.c` are generated from IBM Plex Sans Regular with
[lv_font_conv](https://github.com/lvgl/lv_font_conv) (MIT). The converter runs
on a workstation only; the firmware ships the generated C.

## Art

No photographic or vector assets are bundled. The camera test patterns, the
canvas applets, and every drawing on screen are generated by this repository.

## How credit is surfaced

- This file is linked from the README.
- License texts for LVGL, Montserrat and Font Awesome stay in their upstream
  packages under `managed_components/` and `third_party/`.
